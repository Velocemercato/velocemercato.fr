# Affiches publiques (dossier d'images)

Importer ici les quatre PNG originaux aux noms définis dans `../affiches-public.json`, sur la branche de la PR. Aucun document VIP, numéro de téléphone ou donnée personnelle ne doit être déposé : ce dossier sera public après fusion.

Avant fusion, vérifier les rencontres, les dates et cotes sur les affiches ; ne pas affirmer que les pourcentages implicites garantissent des gains. La galerie n'affiche que des fichiers effectivement présents et s'arrête automatiquement à l'expiration définie dans le JSON.
