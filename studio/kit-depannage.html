Mode d’emploi et vidéos

Le kit relit les données du site à l’ouverture, puis chaque minute tant que cette page est visible. Il ne publie pas sur tes comptes. Aucun jeton Meta n’est nécessaire.

Instagram et TikTok demandent une image ou une vidéo à joindre dans leur application. Les liens dans une légende ne sont généralement pas cliquables : utilise aussi ton lien de profil. Sur YouTube, colle le texte dans la description d’une vidéo ou dans une publication de communauté si ton compte la propose.

Le repère « déjà partagé » est enregistré uniquement sur cet appareil ; il ne certifie pas une publication sur un réseau.
