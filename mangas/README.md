## Fonctionnement technique
- HTML/CSS/JavaScript statique, compatible GitHub Pages, aucun build ni dépendance.
- Lecteurs YouTube officiels via `www.youtube-nocookie.com/embed/...`, initialisés sur un **clic volontaire**, sans téléchargement ni re-hébergement.
- Les lecteurs peuvent afficher des publicités YouTube et ne doivent pas être contournés.
- Si l'intégration n'est pas autorisée ou la vidéo disparaît, un lien vers YouTube est visible.
- Aucun script publicitaire ni tracking ajouté sur les pages VM MANGAS.
- Métadonnées Open Graph par épisode pour les partages sur les réseaux.
- Navigation ajoutée aux deux menus principaux de `index.html`.

## Pour ajouter une série
1. Vérifier qu'une chaîne officielle ou autorisée publie légalement une vidéo, qu'elle soit intégrable en France et que les conditions d'utilisation permettent la présentation prévue.
2. Ajouter une page éditoriale originale avec attribution et le lecteur YouTube officiel, sans télécharger le fichier.
3. Mettre à jour la carte sur `/mangas/index.html`, les liens internes et idéalement le sitemap.
4. Tester sur ordinateur et smartphone, le blocage éventuel d'intégration et le consentement aux contenus tiers.
5. Ne jamais promettre « sans pub YouTube ». On peut promettre « sans publicité ajoutée par VM MANGAS ».
6. Pour commercialiser la rubrique, conserver une **valeur éditoriale indépendante** (articles, quiz, critiques, analyses, communauté).

## À ne pas confondre
Un site sous `velocemercato.fr/mangas/` n'est **pas** un domaine séparé. Si VM MANGAS reçoit un domaine dédié plus tard, configurer DNS/hébergement, canoniques et liens pour éviter les doublons SEO.
