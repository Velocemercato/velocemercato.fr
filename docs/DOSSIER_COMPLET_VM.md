## 7. Règles du projet

- Les JT et brèves sont **générés par IA** et le disent ; chaque brève cite sa source.
- Aucune statistique de visiteurs publique, aucun chiffre d'audience inventé.
- Démos : entreprises, personnes, avis et coordonnées **fictifs** et marqués comme tels.
- CBD et alcool : **vérification d'âge**, mentions obligatoires (loi Évin : « L'abus d'alcool est dangereux pour la santé, à consommer avec modération »).
- Projets refusés et pourquoi : annuaire/comparateur d'escortes (proxénétisme), site de liens vers vidéos adultes (vérification d'âge Arcom, piratage, interdit par GitHub), vente d'alcool entre particuliers (licence obligatoire).
- Orthographe : « detailing » sans accent ; « boxes » est correct.

## 9. Tout remettre en ligne en 10 minutes

Si un site disparaît (dépôt supprimé, compte perdu…) :

1. Sur GitHub, créer un dépôt **public** du même nom (ex. `velocemercato.fr`) sur le compte Velocemercato.
2. Décompresser le ZIP du site et envoyer tous les fichiers dans le dépôt (bouton *Add file → Upload files*, ou demander à un assistant de le faire).
3. *Settings → Pages* : Source = branche `main`, dossier `/ (root)`. Le fichier `CNAME` remet le domaine (`velocemercato.fr` ou `vmunivers.fr`). Cocher *Enforce HTTPS*.
4. Chez le registrar du domaine, vérifier les DNS de GitHub Pages : enregistrements A vers `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, et `www` en CNAME vers `velocemercato.github.io`.
5. Pour velocemercato.fr uniquement : recréer les **secrets et variables** (partie 6), puis *Actions → Enable workflows*. Les robots repartent tout seuls.
6. Vérifier : les pages s'ouvrent, un robot (ex. *Veloce Mercato - Actualites*) lancé à la main termine en vert.

Les vidéos des anciens JT (branche `tv`) ne sont pas dans les ZIP : les robots en recréent de nouvelles dès le premier passage.
