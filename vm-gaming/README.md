# VM GAMING

Page simple : rejoindre le Discord, choisir son jeu, jouer.

- Aucun compte, aucune donnée de joueur enregistrée.
- `data/events.json` : uniquement de vrais rendez-vous. La rubrique « Prochaines soirées » reste cachée tant qu'il n'y en a pas.
  Exemple : `[{"date":"2026-11-06T21:00:00+01:00","titre":"Soirée Warzone","jeu":"Warzone"}]`
- Pas de logos officiels des jeux. Mention de non-affiliation en pied de page.

## Discord conseillé

Un salon par jeu : #warzone, #redsec, #fc, #gta-vi, plus #bienvenue, #règles, #général.
